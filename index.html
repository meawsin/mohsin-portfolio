Ki Oushodh (কি ঔষধ)

Accessibility-first medicine identifier for Bangladesh

← Drag or swipe to view screens →

I built this because my grandmother cannot read medicine strips. Most health apps assume literacy and internet access, two things a large part of Bangladesh's elderly population lacks.

The app runs Google ML Kit OCR on-device to extract text from camera frames, then matches against a bundled SQLite database of 13,929 Bangladeshi medicines (brand name to generic name lookup) using fuzzy string matching. No server, no API calls, no latency. When connected, a Wikipedia API fallback handles unrecognized drug names.

Results are read aloud via Android's native Text-to-Speech engine in Bangla or English, with automatic language fallback for devices that lack a Bengali voice pack. The entire interface is designed for one-handed use: adjustable font scaling, high-contrast mode, portrait-locked layout, 30-day scan history.

Stack: Flutter · Dart · ML Kit OCR · SQLite · TTS

ACES Scanner

Automated Contact Extraction & Sync (Startup Bangladesh Limited)

At Startup Bangladesh Limited, staff collect hundreds of physical visiting cards across startup summits and investor sessions. Manually transcribing card details into corporate spreadsheets was slow and caused typos. I built ACES to replace manual data entry with an automated mobile capture and ingestion pipeline.

The Flutter client runs Google ML Kit Vision API directly on the phone. A custom state machine prompts the user to align the card's front, triggers a haptic confirmation upon text detection, shifts to the back side (with a single-sided skip button), and shuts down the camera stream immediately to preserve memory and battery.

Raw text strings hit a Laravel REST middleware. The backend prompts an LLM with strict JSON schemas to parse messy names, designations, phone numbers, and addresses while correcting OCR typos. Laravel then queries Microsoft SharePoint via Microsoft Graph API to detect conflicts (promotions, job changes, duplicate contacts) before committing verified rows to the enterprise directory.

Recent scans cache locally in Hive for instant offline history access. The architecture decouples the mobile client from the storage layer, allowing future backend migrations without modifying the mobile application.

Stack: Flutter · Dart · ML Kit Vision · Laravel · LLM API · MS Graph · Hive

AgriApp Ecosystem

Agricultural Marketplace, Quality Control & Escrow Platform

Smallholder farmers in Bangladesh often struggle with middlemen exploitation, unpredictable crop pricing, and lack of verified quality standards. AgriApp is a multi-role agricultural supply chain platform designed to connect farmers, field agents, retailers, and administrators in a single verified ecosystem.

The system enforces a dedicated Quality Control layer before product dispatch: moisture percentage tracking, freshness rating, pest-free status, and photographic inspection. To prevent fraud, payments are held in escrow and released only after the buyer and quality agent confirm delivery standards. A disaster management module enables emergency fund allocations for crop damage.

The mobile client is built in Flutter with local SQLite storage for offline record-keeping in rural regions with poor cellular connectivity, synchronizing once connection is restored. The backend runs on Node.js and Express with JWT role-based access control and MongoDB data models.

Stack: Flutter · Dart · Node.js · Express · MongoDB · SQLite · Escrow

Tour Buddy

Collaborative travel finance tracker

← Drag or swipe to view screens →

Group trips frequently end with confusion over shared costs, uneven payments, and chasing friends in chat groups. I built Tour Buddy to handle expense tracking and settlement across all trip members in real time.

The app uses an algorithmic debt settlement model that simplifies multiple cross-member debts into the minimum possible transactions, eliminating circular payments. Real-time data syncs across devices using Firebase Firestore, with atomic array operations (FieldValue.arrayUnion and arrayRemove) preventing race conditions or stale overwrites during concurrent updates.

Includes budget alert thresholds (50%, 80%, 100%), multi-currency support with offline exchange rate fallbacks, interactive spending analytics, and a formatted PDF financial ledger export with itemized tables and grand totals. Supports Google Sign-In with anonymous account migration.

Stack: Flutter · Dart · Firebase Firestore · Auth · PDF
